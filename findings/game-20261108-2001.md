## Probe fix (2.1, 2026-11-08)
- The per-tick function is the virtual `World::Simulate` (SimEngine.dll RVA 0x6C480, it bumps the tick
  counter at `[this+1B8h]`). The exe imports no `Simulate`, only SimulatePre/Post, so it reaches
  `World::Simulate` through a vtable.
- fpu-probe 2.1 writes a 5-byte jump over its first bytes (`51 53 56 8B F1`, checked first) to a stub
  that pins cw=007F mx=1F80 before and after every tick. Self-test passes (11 checks).
- In the next game, check that `PIN  ticks=` keeps growing on every PC (about 8 per second).
  The install script's report now has a check for this.
